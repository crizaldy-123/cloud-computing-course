# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides many different services for businesses, organizations, developers, and individuals. It provides computing, storage, networking, databases, security, and other cloud services that can be used to build and run applications without having to maintain all the physical hardware themselves.

AWS is designed to be scalable, so users can increase or decrease their resources depending on their needs. This makes it useful for small applications as well as large enterprise systems.

## Global Infrastructure

AWS has a global infrastructure made up of geographic Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS Regions are connected by high-bandwidth and low-latency networking, allowing applications to be designed for high availability and fault tolerance.

AWS currently lists 39 geographic Regions and 123 Availability Zones, with additional infrastructure announced for the future. Its infrastructure covers areas such as North America, South America, Europe, Asia Pacific, the Middle East, Africa, and Australia and New Zealand.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS cloud services. Users can use the console to create and manage resources, configure services, monitor their cloud environment, and control access to their AWS account.

The console provides access to many AWS services from one web interface, making it easier for users to manage their cloud resources without having to use only command-line tools.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides scalable computing capacity in the AWS Cloud. It allows users to create virtual servers called instances and choose different combinations of computing, memory, storage, and networking resources depending on their workload.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data. Users organize their files and other data as objects inside storage containers called buckets. S3 can be used for backups, websites, applications, data lakes, and many other types of data storage.

### 3. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated virtual network in AWS. Users can configure IP addresses, subnets, route tables, gateways, and other networking features to control how their AWS resources communicate with each other and with other networks.

### 4. AWS IAM

AWS Identity and Access Management (IAM) is used to control access to AWS resources. It allows administrators to create users, groups, and roles and use policies to determine what actions they are allowed to perform. This helps organizations manage permissions and protect their cloud resources.

## Three Advantages

### 1. Wide Range of Services

AWS provides a large selection of cloud services covering areas such as computing, storage, databases, networking, security, analytics, and machine learning. This allows organizations to build many different types of applications using services from the same cloud provider.

### 2. Global Infrastructure

AWS operates infrastructure across many geographic Regions and Availability Zones around the world. This allows organizations to deploy applications closer to their users and design systems that can remain available even when problems affect a particular location.

### 3. Scalability

AWS allows organizations to increase or decrease their cloud resources depending on their workload. For example, computing resources can be increased when an application experiences high traffic and reduced when demand decreases. This helps businesses avoid maintaining unnecessary physical hardware.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for hosting websites and applications, storing and backing up large amounts of data, running databases, and supporting business systems. Companies can also use AWS for data analytics, artificial intelligence and machine learning, disaster recovery, and large-scale application development.

For example, an e-commerce company can use Amazon EC2 to run its application servers, Amazon S3 to store files and data, Amazon VPC to create its private network, and AWS IAM to manage access to its resources.
