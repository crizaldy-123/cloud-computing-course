# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services that organizations can use to build, deploy, manage, and run applications and other IT workloads. Azure provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and more.

Azure can support organizations of different sizes, from small applications to large enterprise systems. It also works closely with other Microsoft technologies, making it useful for organizations that already use products such as Windows Server, Microsoft 365, and Active Directory.

## Global Infrastructure

Azure operates a global cloud infrastructure made up of geographic regions and data centers. Azure regions are geographic locations that contain one or more data centers connected through a dedicated regional network.

Azure also provides Availability Zones in supported regions. These are physically separate locations within an Azure region that have independent power, cooling, and networking. They can help organizations design applications that remain available even if one location experiences a problem.

## Cloud Management Console

The main web-based management interface for Azure is the Azure portal. The Azure portal allows users to create, configure, monitor, and manage Azure resources and services through a graphical interface.

Administrators can use the portal to manage virtual machines, storage accounts, databases, networking resources, security settings, and many other cloud services. Azure also provides command-line and scripting tools for users who prefer to manage resources through commands.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides scalable computing resources that allow users to run Windows or Linux virtual machines in the cloud. Organizations can select different virtual machine sizes depending on their processing, memory, storage, and networking requirements.

### 2. Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service for storing large amounts of unstructured data. It can store files such as documents, images, videos, backups, and application data.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure. It provides networking features such as subnets, IP addresses, routing, and network security controls so that Azure resources can communicate securely.

### 4. Microsoft Entra ID

Microsoft Entra ID, formerly known as Azure Active Directory, is Microsoft's cloud-based identity and access management service. It helps organizations manage users, applications, devices, and access to cloud resources.

## Three Advantages

### 1. Strong Microsoft Integration

Azure integrates closely with Microsoft's existing products and technologies. Organizations using Windows Server, Microsoft 365, and Microsoft identity technologies can connect their existing environments with Azure services.

### 2. Global Availability

Azure provides cloud infrastructure in many regions around the world. Organizations can deploy applications in appropriate geographic locations to improve availability and provide better access for users in different areas.

### 3. Enterprise Features

Azure provides many services designed for enterprise environments, including identity management, security, networking, databases, analytics, and application development. These services can help large organizations manage their existing IT infrastructure while gradually moving workloads to the cloud.

## Typical Enterprise Use Cases

Azure is commonly used by organizations for application hosting, virtual machines, databases, data storage, networking, identity management, analytics, and artificial intelligence. It can also be used for hybrid cloud environments where some systems remain on-premises while other workloads are moved to the cloud.

For example, a university that already uses Windows Server, Microsoft 365, and Active Directory could use Azure Virtual Machines for cloud-based servers, Azure Virtual Network for its cloud networking, and Microsoft Entra ID for managing identities and access.
